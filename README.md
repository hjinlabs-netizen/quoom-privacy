# Quoom Privacy Policy

Official repository hosting the Privacy Policy and Terms of Service for Quoom, a secure, decentralized communication terminal developed by Alpha Pulse.

The public policy page is available at:

<https://github.com/hjinlabs-netizen/quoom-privacy>

The current application release is **Quoom 1.0.5**. The policy page supports English, Simplified Chinese, Turkish, Russian, Azerbaijani, Korean, and German.
